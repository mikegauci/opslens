# Reconcile a chart with Activity

ID: RUN-DRILL
Version: 1
Effective: 2026-11-08
Scope: runbooks
Status: current
Source: knowledge/documents/run-drill-v1.md

Open the provider or day link directly from Overview. Confirm settlement basis, settled status, the exact UTC interval, brand/provider filters and the originating dataset hash. A day link narrows the interval to that UTC day. A provider link narrows the provider dimension.

Inspect the scoped rows with stable server sorting. If the snapshot changed during navigation, return to Overview and open a fresh link. A manually changed date basis, filter or status creates a different analytical selection.
