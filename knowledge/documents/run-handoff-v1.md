# Record an investigation handoff

ID: RUN-HANDOFF
Version: 1
Effective: 2026-11-08
Scope: runbooks
Status: current
Source: knowledge/documents/run-handoff-v1.md

Include the date basis, UTC bounds, filters, as-of timestamp, dataset hash and signed EUR change in the handoff. Attach the matching Activity link and the verified metric or provider evidence. Cite the versioned definition that explains each rule used.

Separate the observed contributor from possible explanations. If the requested cause depends on external telemetry, state the gap and name the record that could resolve it. If a previous export uses different scope or freshness, keep its conclusions tied to that export.
