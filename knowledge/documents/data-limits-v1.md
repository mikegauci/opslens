# Evidence boundaries of the synthetic dataset

ID: DATA-LIMITS
Version: 1
Effective: 2026-11-08
Scope: data
Status: current
Source: knowledge/documents/data-limits-v1.md

The v1 data contains fictional bets, anonymous synthetic player IDs and EUR minor units. It represents one final-state view. It omits bonuses, cash-out accounting, partial settlement and subsequent corrections.

OpsLens has no provider uptime telemetry, incident tickets, fraud decisions, customer identities or external operator ledgers. A payout pattern can support a description of observed payouts. Proving an outage, fraud or an external settlement problem requires evidence from a separate system.
